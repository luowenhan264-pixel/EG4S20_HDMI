# topic1_hdmi_player 代码说明（终稿）

本工程为竞赛选题一终稿：**TF 卡 playlist 读图 → SDRAM 双缓冲 → HDMI 视频 + 48 kHz 测试音**，单一 top / 单一 bit。

## 顶层

- 文件：`src/user_source/hdl_source/top_tf_hdmi_audio.v`
- 模块名：`top`
- 工程：`src/td_project/topic1_hdmi_player.al`

## 相对例程的关键改动

| 模块 | 改动 |
|------|------|
| `top` | ex4 风格 POR（sys/video lock + 20 ms）且 `rst_all \|= ~audio_pll_lock`；保留 ex5 音频通路；playlist 参数；OSD 叠加 |
| `sd_card_bmp.v` | 固定扇区 playlist，不再全盘盲扫；`AUTO_PERIOD_MS`；load timeout / abort / `write_done_seen` |
| `bmp_read.v` | 合并 `load_abort` |
| `osd_overlay_640x480.v` | 左上角色块 OSD |
| `sys_pll` / `video_pll` | 引出 `extlock` 供 POR |

详见根目录 `进度说明.md`。
